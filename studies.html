04 / Methods

Studies

High-level study directions connect the research questions to evidence without publishing executable protocols before formal release.

Public study directions

This page deliberately stays above executable protocol level. Exact hypotheses, operational definitions, assignment logic, thresholds, scoring rubrics and analysis plans remain private until they are formally preregistered, released with a preprint, or otherwise ready for public scrutiny.

S01 / Core direction

Selective persistence

Can experience have different persistence depths without turning either stability or change into the default?

Public question
Which kinds of effects should remain transient, which should remain autobiographical, and which warrant enduring character change?
Evidence sought
A comparison that keeps identity continuity, later behavioural change and memory retention as distinct outcomes.
Not public yet
Exact policy definitions, event construction, scoring rules, thresholds, sample design and analysis plan.

S02 / Adjacent direction

Revision after correction

When the grounds for a lesson change, can the system preserve the history of what happened while revising what it currently endorses?

Public question
How should autobiographical retention interact with belief revision and later behaviour?
Evidence sought
Historical memory remains available while unsupported downstream influence can be revised.
Not public yet
Correction fixtures, dependency representation, evaluation prompts and quantitative decision criteria.

S03 / Secondary systems direction

Interaction regimes

Do experiences acquired under different interaction regimes contribute differently to later state and behaviour?

Public question
Whether dialogue and out-of-dialogue experience are functionally interchangeable once they enter a persistent system.
Evidence sought
Downstream differences that cannot be explained merely by unequal exposure or retrieval.
Not public yet
Condition structure, exposure matching, timing, model configuration and analysis details.

Release policy

Methods

With results

Evidence package

Analysis, limitations and reproducible artifacts should be released with the corresponding scholarly output where possible.

Privacy-preserving path

Controlled work should use synthetic or public fixtures wherever possible. Private production logs and personal histories are not required to test the core persistence questions.
