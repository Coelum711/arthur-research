# 内容维护

八个 HTML 页面是公开正文，直接修改 `<main>` 内容即可。没有生成器或后台。

## 证据标签

- **Naturalistic observation**：只有在材料已经明确匿名化、方法上下文足够且公开必要性成立时才发布；不等于因果证据。
- **Proposed / not run**：尚未执行；不要填写结果语气或假数字。
- **Controlled result**：执行后才使用；附冻结方案、条件、样本、版本、数据、分析与局限。
- **Abstract-level note**：只核对摘要或元数据；全文阅读后再标注更高阅读范围。
- **Research interpretation**：本站的假设或推论，与来源作者主张分开。

## 隐私原则

公开内容默认使用 synthetic / public fixtures。不得发布研究者真实姓名、单位、邮箱、位置等现实身份信息；不得发布私人角色履历、私密对话、关系、地点历史、内部日记、原始行为轨迹、生产 prompt、raw logs 或源码。

若未来确需发布 naturalistic evidence，应先确认研究主张所需的最小证据，再做去标识化与人工复核。能够用合成材料回答的问题，不应依赖私人运行记录。

## 研究方案

`studies.html` 只公开高层 study directions。可执行 protocol、operational definitions、分组逻辑、阈值、样本设计与分析方法保留在私有研究记录中，直到适合 preregister / archive / 随论文发布。
